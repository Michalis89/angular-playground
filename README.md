# Angular Playground

🚀 A personal Angular 19+ playground for experimenting with **RxJS** and **Angular features**.
Built as part of my preparation for senior front-end interviews.

## 📌 Features

- Angular 19 standalone components
- RxJS demos:
  - Observables & Subscriptions
  - Operators (`switchMap`, `mergeMap`, etc.)
  - Subjects & BehaviorSubject as state management
  - Error handling, retry strategies
- Angular concepts:
  - Signals
  - Forms (Reactive & Template-driven)
  - Change Detection strategies
- Navigation Sidebar to access all demos

## 🛠️ Tech Stack

- Angular 19
- RxJS 7+
- SCSS
- TypeScript

## 🎯 Goal

This project is my **learning lab** and a **public reference** for RxJS/Angular concepts.
It also supports content creation for my Medium articles.
